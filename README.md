# Traffy Bangkok Complaint Geo-Analytics Dashboard

Built an interactive Streamlit dashboard for exploring Bangkok Traffy complaint data.

## Features
- Complaint filtering by type and date range
- Scatter map and heatmap visualization with PyDeck
- DBSCAN and KMeans clustering for hotspot discovery
- SQLite-backed data loading
- Bangkok POI overlays: bus stops, transit stations, 7-Eleven, places of worship
- GeoPandas preprocessing for Bangkok-boundary filtering

## Tech Stack
Python, Streamlit, Pandas, PyDeck, SQLite, scikit-learn, GeoPandas, Shapely
